# 퀴즈 플레이

교사가 O/X와 객관식 퀴즈를 만들고, 학생들이 PIN 또는 QR 코드로 참가하는 실시간 퀴즈입니다. GitHub Pages와 Firebase Realtime Database를 사용합니다.

## 퀴즈 만들기

1. 시작 화면에서 **퀴즈 만들기**를 선택합니다.
2. Google 계정으로 로그인하고 제목, 게임 배경, O/X 또는 객관식 문제를 입력합니다. 각 문제의 이미지, 정답, 해설과 제한 시간을 설정할 수 있습니다.
3. **저장하기**를 누르면 시작 화면의 **내 퀴즈**에서 수정하거나 게임을 시작할 수 있습니다.

**원고로 퀴즈 만들기**에 30~15,000자의 원고를 붙여 넣고 유형과 문제 수를 선택하면 AI가 문제 초안을 추가합니다. 원고는 AI 서비스에 전송됩니다. 정답·해설을 확인하고 수정한 뒤 저장하세요. 퀴즈 생성은 같은 Gemini API를 사용하는 사연 서비스와 사용량을 공유합니다. 퀴즈 생성은 계정당 하루 10회, 전체 하루 100회, 요청 간격 10초로 제한합니다.

퀴즈는 로그인한 계정의 Firebase 공간에 저장됩니다. 같은 Google 계정으로 로그인하면 다른 기기에서도 불러올 수 있습니다. 기본 컴퓨터 상식 퀴즈는 로그인 없이 사용할 수 있습니다.

## 실시간 게임

1. 진행자가 퀴즈 카드의 **게임 시작**을 누르면 PIN과 QR 코드가 나타납니다.
2. 참가자는 QR 코드를 찍거나 참가 화면에 PIN과 닉네임을 입력합니다.
3. 진행자가 게임을 시작하면 참가자는 휴대폰으로 답을 제출합니다. 각 문제의 정답, 해설, 응답 수와 순위가 표시되고 마지막에 최종 결과가 나옵니다.

맞힌 답은 500점에 빠른 응답 보너스 최대 500점이 더해집니다. 실시간 게임에는 인터넷과 Firebase 연결이 필요합니다. 교사용 **학습 결과**에서 학생별·문제별 정답률, 평균 응답 시간, 오답 복습과 CSV 리포트를 확인하고 삭제할 수 있습니다. 학생은 저장 버튼이나 Google 로그인 없이 PIN·닉네임으로 참가합니다.

**자율 학습**은 학생별로 제한 시간이 시작되며, 제출 후 정답·해설을 확인하고 다음 문제로 진행합니다. 새로고침해도 이미 제출한 답과 시작 시간은 유지됩니다. 진행자 창을 닫아도 학습할 수 있고 결과 화면을 열면 최신 응답을 분석합니다. 진행자는 같은 브라우저에서 같은 퀴즈·모드로 다시 들어가 방을 복구하거나 학습을 종료할 수 있습니다. Google 계정의 결과는 다른 기기에서도 조회할 수 있고 기본 퀴즈 체험 결과는 생성한 브라우저의 임시 계정에 연결됩니다.

## Firebase 설정

`js/config.js`에 Firebase 웹 앱 설정을 넣고 Realtime Database를 활성화합니다.

1. Firebase Authentication의 로그인 제공업체에서 **Google**을 사용 설정합니다.
2. Authentication의 승인된 도메인에 사이트 도메인(예: `patrickdfg.github.io`)을 추가합니다.
3. Realtime Database 규칙에 저장소의 `database.rules.json`을 참고하여 `quizzes/$uid` 규칙을 추가합니다. 이 규칙이 실제로 적용되어야 각 계정이 자신의 퀴즈만 읽고 쓸 수 있습니다. 같은 Firebase 프로젝트를 다른 앱과 공유한다면 기존 규칙을 지우지 말고 필요한 부분만 합칩니다.

4. Authentication에서 **익명** 로그인을 활성화합니다. 학생의 익명 UID는 자기 응답만 제출하도록 권한을 구분하는 데 사용하고 실명·이메일은 수집하지 않습니다.

새 방은 `sessions/{pin}`을 사용하며 진행 상태·점수는 진행자만 수정합니다. 학생은 자기 닉네임으로 참가하고 현재 문항에 서버 시각으로 한 번만 답할 수 있습니다. 자율 학습의 정답 키는 `sessionKeys`에 분리되어 해당 학생이 답을 제출한 문항만 읽을 수 있습니다. 결과는 `reports/{teacherUid}`로 격리합니다. PIN을 공유받은 참가자에게 닉네임·게임 응답은 보이므로 민감한 내용을 입력하지 마세요. 진행자는 채점을 수행하는 신뢰 주체입니다.

`games`의 기존 데이터는 보존하되 쓰기는 닫습니다. 이전 버전의 진행 중 방은 새로 열어야 하며 기존 HTML 주소·퀴즈 저장 경로·데이터 형식은 유지합니다. 결과 삭제는 해당 방·정답 키·결과를 함께 삭제합니다.

## 검사

## 우주 경주와 클래스

**우주 경주**는 별도의 새 게임 모드입니다. 성운 항로의 우주선은 기존 정답·속도 점수를 그대로 사용하며 총 가능한 점수 대비 위치를 표시합니다. 수업 모드와 동일한 진행·공동 순위·시상대와 음소거 설정을 사용합니다.

**우리 클래스**에서 Google 교사 계정으로 클래스를 만들고 8자리 코드를 학생에게 알려 주세요. 학생은 익명 참가와 닉네임만 사용합니다. 교사는 저장된 퀴즈를 자율 학습으로 배정하고 학생별 누적 정답률·응답 시간·점수를 조회합니다. 같은 브라우저의 익명 UID로 누적하므로 다른 기기나 브라우저를 사용하면 다른 학생으로 집계됩니다. 학생 자신의 저장·계정 관리 기능은 없습니다.

클래스 명단과 기록은 소유 교사만 읽을 수 있습니다. 배정과 해당 세션은 클래스 회원만 접근합니다. 교사는 학생의 참가·관련 응답, 개별 배정·관련 방·결과, 클래스 전체 기록을 삭제할 수 있습니다. 원래 저장 퀴즈는 삭제하지 않습니다. 일반 결과 화면에서 클래스 배정 결과를 삭제해도 배정 목록에서 함께 제거됩니다.

## 검사 실행

Node 24, Java 21 환경에서 `npm ci --ignore-scripts`, `npm test`, `npm run test:rules`로 AI·채점·리포트 및 실제 Firebase 규칙 에뮬레이터 검사를 실행합니다. 규칙 검사는 운영 데이터에 접근하지 않는 `demo-quiz-play` 프로젝트를 사용합니다. GitHub PR에서도 같은 검사를 실행합니다.
