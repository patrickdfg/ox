# 퀴즈 플레이

교사가 O/X와 객관식 퀴즈를 만들고, 학생들이 PIN 또는 QR 코드로 참가하는 실시간 퀴즈입니다. GitHub Pages와 Firebase Realtime Database를 사용합니다.

## 퀴즈 만들기

1. 시작 화면에서 **퀴즈 만들기**를 선택합니다.
2. 제목, 게임 배경, O/X 또는 객관식 문제를 입력합니다. 각 문제의 정답, 해설과 제한 시간을 설정할 수 있습니다.
3. **저장하기**를 누르면 시작 화면의 **내 퀴즈**에서 수정하거나 게임을 시작할 수 있습니다.

퀴즈는 만든 기기의 해당 브라우저에 저장됩니다. 다른 기기나 브라우저와 자동으로 동기화되지 않으며, 브라우저 데이터를 삭제하면 저장한 퀴즈도 삭제됩니다. 기본 컴퓨터 상식 퀴즈도 사용할 수 있습니다.

## 실시간 게임

1. 진행자가 퀴즈 카드의 **게임 시작**을 누르면 PIN과 QR 코드가 나타납니다.
2. 참가자는 QR 코드를 찍거나 참가 화면에 PIN과 닉네임을 입력합니다.
3. 진행자가 게임을 시작하면 참가자는 휴대폰으로 답을 제출합니다. 각 문제의 정답, 해설, 응답 수와 순위가 표시되고 마지막에 최종 결과가 나옵니다.

맞힌 답은 500점에 빠른 응답 보너스 최대 500점이 더해집니다. 실시간 게임에는 인터넷과 Firebase 연결이 필요합니다. 결과는 현재 게임에서 확인할 수 있으며 별도로 저장되지는 않습니다.

## Firebase 설정

`js/config.js`에 Firebase 웹 앱 설정을 넣고 Realtime Database를 활성화합니다. 기존 수업용 규칙은 다음과 같습니다.

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "games": {
      "$pin": { ".read": true, ".write": true }
    }
  }
}
```

이 규칙은 PIN을 아는 누구나 해당 게임 데이터를 읽고 수정할 수 있으므로 신뢰할 수 있는 수업 환경에서 사용해야 합니다. 진행 중 문제의 정답은 공개 단계까지 게임 데이터에 넣지 않지만, 이 규칙 자체가 참가자의 조작을 막지는 않습니다. 게임 기록은 Firebase 콘솔의 `games`에서 정리할 수 있습니다.
